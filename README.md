# Windows Cloud Development Environments

This repository contains Terraform configurations for setting up Windows development environments in both Google Cloud Platform and Amazon Web Services.

## Repository Structure

- `gcloud/` - Google Cloud configuration for Windows Server workstation

## Quick Start

1. Choose your preferred cloud provider:
   - [Google Cloud Setup Instructions](gcloud/README.md)

2. Follow the provider-specific instructions for deployment

## Environment Comparison

### Google Cloud Platform (GCP)
- Uses Compute Engine VMs with Windows Server
- Direct VM control and customization
- More technical setup but potentially lower cost
